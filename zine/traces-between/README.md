## PDF ja tulostus

A4 vaaka, mittakaava 100 %, ei selaimen ylä-/alatunnisteita eikä lisämarginaaleja. Vasemmalla on 23 mm sidontavaraa. Tulostuksen lähtökohta on yksipuolinen kierresidottava zine. Tarkista lopullisen PDF:n sivumäärä, ylivuodot ja kuvien laatu ennen tulostusta. Testaa QR-koodit paperivedoksesta. Osa sivuista lasertulosteita, valokuvasivut mustesuihkutulosteita.
