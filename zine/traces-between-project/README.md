# TRACES BETWEEN — project zine

Yleiskäyttöinen, päivittyvä zine TRACES BETWEEN -teosperheestä.

## Tarkoitus
- apurahahakemusten liite
- portfolio
- näyttelyehdotukset
- projektin esittely
- verkkoversio, PDF ja A4-vaakatuloste samasta lähteestä

Tämä julkaisu on sisällöllisesti erillinen opinnäytetyön taiteellisen työn dokumentaatiosta.

## Hakemisto

`zine/traces-between-project/`

jolloin verkkoversio on:

`https://photodiarygame.com/zine/traces-between-project/`

## Nykyinen versio
Versio 0.1 käyttää väliaikaisesti jo olemassa olevan dokumentaatiozinen kuvia julkisina URL-osoitteina, jotta rakenne toimii heti.

Kun kuvat on kuratoitu, kopioi valitut kuvat tämän hakemiston omaan `assets/images/`-hakemistoon ja vaihda HTML:n kuvapolut paikallisiksi.
