
# A Memory Without an Owner
## Visual Reference 1.0

**Reference version:** MPE 0.8 — Changing Ghosts  
**Date:** 20 November 2026  
**Project family:** Traces Between

### Visual identity

The artwork uses a restrained, mysterious and partially
obscure visual language.

Its principal visual elements are:

- A 2:1 panoramic canvas
- Dark, heavily pixelated photographic ghost layers
- Randomly selected photographs from a curated collection
- Small luminous points representing abstract memory forms
- Fine, partially transparent connections between points
- Organic, translucent memory fields
- Slow visual transformations
- Subtle typographic traces
- A wandering point and its delicate path

### Artistic principles

The artwork does not need to explain itself immediately.

Ambiguity, silence, incompleteness and slow transformation
are essential parts of its visual identity.

The photographic layer is not the artwork itself.
It is one way of perceiving the collective memory.

### Preservation

This reference version should remain unchanged.

Future versions may introduce new algorithms, inputs,
rendering methods and exhibition environments, but
their visual decisions should be evaluated against
this reference.

### Reference statement

*The memory remains. The image changes.*
