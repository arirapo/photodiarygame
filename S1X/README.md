# SIX 1.3 – JSON-kuvat

Lataa kuusi neliönmuotoista JPG-, PNG-, WEBP- tai SVG-kuvaa `images`-hakemistoon ja päivitä polut `images.json`-tiedostoon. Kuvia ei tarvitse pilkkoa: selain jakaa jokaisen kuvan automaattisesti 3 × 3 -ruudukoksi.

Säilytä sivuluokat `front`, `right`, `top`, `left`, `back`, `bottom`. Suositeltu koko on esimerkiksi 1200 × 1200 px. Julkaise koko kansio GitHub Pagesissa.
