# S1X: Sixth Face 1.0

S1X-pelin henkilökohtainen versio, jossa pelaaja voi tehdä kuution kuudennesta sivusta omansa.

## Ominaisuudet

- Pelaaja voi valita kuvan omalta laitteeltaan.
- Kuva rajataan automaattisesti keskeltä neliöksi.
- Kuva pienennetään selaimessa 1200 × 1200 pikseliin.
- Kuva tallennetaan vain kyseisen laitteen selaimen IndexedDB-tallennukseen.
- Kuvaa ei lähetetä palvelimelle.
- Selain jakaa kuvan automaattisesti 3 × 3 -ruudukoksi.
- Keskeneräistä peliä voi jatkaa.
- Uusi peli nollaa etenemisen, käytetyt koodit ja peliajan.
- Uusi peli säilyttää valitun kuudennen kuvan.
- Kuva voidaan poistaa erillisellä Poista kuva -painikkeella.

## Julkaiseminen

Vie koko kansio GitHub Pagesiin. Säilytä `index.html`, `images.json` ja `images/` samassa kansiorakenteessa.
